# Handoff: 무타공랩 중문 커스터마이저 (12-22 샘플)

## Overview
무타공랩 홈페이지 '커스터마이징' 페이지용 중문 구성기. 사용자가 제품 유형·색상·안전창(유리)·간살·손잡이를 선택하면 해당 SKU의 SVG 이미지가 실시간으로 교체되어 미리보기에 표시된다. 알루미늄 프로파일 프레임(A)과 그 내경에 설치되는 중문(B)이 레이어로 합성된다.

## About the Design Files
이 번들의 파일은 **HTML로 제작된 디자인 레퍼런스**(프로토타입)다. 프로덕션 코드로 그대로 복사하지 말 것. 대상 코드베이스(React, Vue 등 기존 환경)의 패턴과 라이브러리로 **재구현**하는 것이 과제다. 환경이 없다면 적절한 프레임워크를 선택해 구현한다. SKU SVG 이미지 자산은 그대로 사용 가능하다.

## Fidelity
**High-fidelity.** 이미지 자산(SVG)은 최종본이며, 옵션 패널 UI는 구조·동작 기준의 참고용(사이트 디자인 시스템에 맞춰 스타일 적용 가능).

## 핵심 구조: 레이어 합성
미리보기는 3개 레이어를 겹친다 (아래→위):
1. **배경 이미지** (선택 시) — 내경 영역에 clip, 유리 비침 확인용
2. **중문 B 이미지** — 내경 위치에 배치
3. **프레임 A 이미지** — 전체
4. (그 위) **간살 오버레이 SVG** — 세로살/가로살/아치를 실시간으로 그림

### 좌표계 (12-22, 단위 mm)
- 프레임 A 전체: W1200 × H2200 (연장 시 H2230)
- 프로파일 단면 3030 (정면 폭 30, 깊이 100 = 30+40+30)
- 구성: 서브 프레임(∏자, H70) + 조절볼트 노출 30(연장 시 60) + 메인 프레임(∏자, H2100)
- **내경(중문 영역): x=30, y=130(연장 시 160), W1140 × H2070**
- 중문 이미지의 viewBox는 `0 0 1140 2070` — 내경에 1:1로 맞춰 배치
- 화면 스케일: 프리뷰 382px 폭 기준 scale = 382/1200

## SKU 이미지 파일 규칙
`skus/12-22/` 아래:
- **A 프레임**: `A/A_12-22_sv.svg` (실버), `A/A_12-22_sv_ext.svg` (+30mm 연장)
- **B 중문 (3연동)**: `B/B_12-22_{색상}_{유리}_{간살}_{손잡이}.svg`
- **B1 중문 (원슬라이딩)**: `B1/B1_12-22_{색상}_{유리}_{간살}_{손잡이}.svg`

코드:
- 색상: `wh` 화이트 / `gr` 그레이(#707074) / `bk` 블랙(#2b2b2e)
- 유리: `cl` 투명 / `br` 브론즈 / `mi` 미스트 / `mo` 모루 / `sa` 샤틴 / `fa` 패브릭
- 간살(파일): `no` 없음 / `ho` 가로 / `ve` 세로 — **커스터마이저는 `no`만 사용**하고 간살은 오버레이로 그림
- 손잡이: `st` 기본(오픈 루프) / `rd` 반원형 / `ba` 긴 바형 / `sb` 짧은 바형

총: A 2장 + B 216장 + B1 216장 (유리 6 × 색상 3 × 간살 3 × 손잡이 4)

## Screens / Views
### 커스터마이저 (단일 화면)
- 좌: 미리보기 (프레임+중문 합성, 상단/좌측 간살 눈금, 하단 `W 1200`·우측 `H 2200/2230` 치수)
- 우: 옵션 패널 (아래 순서)
  1. **제품 유형**: 3연동(기본) / 원슬라이딩 / 스윙폴딩(비활성) / 여닫이(비활성)
  2. **프레임 색상 \***: 실버만
  3. **중문 색상**: 화이트(기본) / 그레이 / 블랙
  4. **안전창**: 투명(기본) / 브론즈 / 미스트 / 모루 / 샤틴 / 패브릭 + **배경 넣기/빼기** 토글(점선 테두리, #b0483a)
  5. **간살**: 안내문 "눈금 알파벳을 클릭해 배치합니다. (상단 대문자 = 세로살, 좌측 소문자 = 가로살)" + 선택 현황 + 간살아치형 / 채움아치형 / 간살 전체 지우기
  6. **손잡이**: 기본(기본값) / 반원형 / 긴 바형 / 짧은 바형 / 일자형(비활성)
  7. SKU 코드 표시
  8. **안내 사항** (내어쓰기): 프레임 가려짐 / 참고용 고지 / "기타 옵션은 고객센터를 통해 문의해 주세요."
- 타이틀 우측: **+30mm 연장** 토글 (볼트 노출 30→60, H 2230, `_ext` 프레임 이미지로 교체)

## Interactions & Behavior
- 옵션 클릭 → 이미지 src 즉시 교체 (선택 버튼: 검정 배경/흰 글자, 비활성: opacity 0.4 + not-allowed)
- **간살 눈금**: 내경 기준 5cm(50mm) 간격
  - 상단 대문자 A~V (50~1100mm, 22개) → 클릭 토글 시 해당 x에 세로살 (rect x=mm-10, y=30, w=20, h=1980)
  - 좌측 소문자 a~am (50~2000mm, 40개) → 가로살 (rect x=30, y=mm-10, w=1080, h=20)
  - 간살 색 = 중문 색상 (wh #eeece7 / gr #707074 / bk #2b2b2e)
- **아치** (오버레이, viewBox 0 0 1140 2070):
  - 간살아치형: `M 30 700 Q 30 120 570 120 Q 1110 120 1110 700` stroke 20, 끝단이 좌우 스타일과 수직 접선으로 연결
  - 채움아치형: 같은 곡선 + `L 1110 30 L 30 30 Z` fill (아치 위 영역 채움)
  - 상호 배타 토글
- **배경 넣기**: 내경 영역에 거실 사진(`uploads/ChatGPT Image 2026년 8월 3일 오전 03_01_08.png`) cover 배치 — 유리 투명도별 비침 비교
- SKU 코드 형식: `{유형} / 12-22 / A-sv / B-{색}-{유리}-{손잡이} / 간살[아치·대문자소문자]`

## 3연동 구동 (참고: Door B.dc.html)
- 3짝, 패널 폭 = (내경 1140 + 겹침 40×2) / 3, 겹침 40
- 순차 개폐: 앞판(1)이 2배속, 중간판(2) 1배속, 3판 고정 — openPct 0~100%
- 깊이(폭) 100 = 프레임과 동일
